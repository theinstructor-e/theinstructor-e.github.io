◆ Lesson Alignment — E03 Media Access Control
MAC addresses operate at Layer 2 (Data Link). They are burned into the NIC and used for communication on the same local network — unlike IP (Layer 3) which routes between networks. MACs are transmitted unencrypted in Ethernet frames, making them visible to anyone sniffing traffic (Wireshark/Kismet) — a key collection and device-tracking consideration for 17E.

ARP — IP to MAC Resolution
17E — ARP SPOOFING: ARP maps a known IP (L3) to a MAC (L2) via broadcast. An attacker can send forged ARP replies associating their MAC with the gateway's IP — intercepting all traffic in a Man-in-the-Middle attack. MAC spoofing also bypasses MAC filtering and hides attacker identity.
