Section 1: Number Systems

Why are numbers important?

As human activities became more complex, numbers became vital for trade, time, distance, and engineering.

In this module, you will learn about number systems in general, and dive deep into the Binary, Octal, and Hexadecimal (Hex) systems specifically.

You will learn the manual methods for converting numbers between these systems and our standard decimal system. These alternative number systems map perfectly to the electronic signals necessary for digital equipment, giving computers their unerring accuracy and speed.

Section 1: Number Systems

The Decimal System (Base-10)

The decimal system is a positional numeral system using ten distinct digits (0–9).

It is the most widely used system in daily life. Each digit in a decimal number has a place value determined by its position relative to the decimal point. For example, in the number 1234:

  • 4 is in the ones place: 4 × 10⁰ = 4
  • 3 is in the tens place: 3 × 10¹ = 30
  • 2 is in the hundreds place: 2 × 10² = 200
  • 1 is in the thousands place: 1 × 10³ = 1000

Adding these values gives the total: 1234.

Section 1: Number Systems

Understanding Positional Notation

Place Value Concept

Each position in a number has a value equal to a power of the base. In the decimal system, the base is 10. The position determines whether the digit represents units, tens, hundreds, etc.

Zero in Positional Notation

The digit 0 acts as a placeholder, indicating that a particular power of 10 has no contribution in that position. This is essential for distinguishing numbers like 205 and 25.

Without zero acting as a placeholder, representing large numbers compactly and performing arithmetic efficiently would be nearly impossible.

Section 1: Number Systems

Summary of the Decimal System

Positional notation is the backbone of the decimal system.

It uses both the digit’s value and its position to determine its total contribution to the number. The digit 0 plays a crucial role as a placeholder to maintain the correct scale of each digit.

Key Takeaways:

  • Decimal system = Base-10 positional system.
  • Value of a digit = digit × (10position).
  • Zero is essential as a placeholder.
  • We use Base-10 simply because humans have 10 fingers. Machines do not.
Section 2: The Binary System

Why Binary?

Computers don't have ten fingers. They only have switches.

Inside a microchip, there are billions of microscopic transistors acting as electronic switches. A switch only has two possible states: ON or OFF.

To a computer:

  • High Voltage (ON) = 1
  • Low Voltage / Ground (OFF) = 0

Because there are only two digits (0 and 1), this is a Base-2 system. We call this the Binary System.

Section 2: The Binary System

Binary Positional Notation

Just like Base-10 uses powers of 10, Base-2 uses powers of 2.

Each box represents a single "Bit" (Binary Digit). In binary, you simply move from right to left, doubling the value of the place every time you move over.

Section 2: The Binary System

Converting Binary to Decimal

If a slot has a 1, turn that value ON. If it has a 0, turn it OFF. Then add them up.

1286432168421
01001011

Looking at the binary number 01001011:

  • We have a 1 in the 64 slot.
  • We have a 1 in the 8 slot.
  • We have a 1 in the 2 slot.
  • We have a 1 in the 1 slot.

64 + 8 + 2 + 1 = 75

Section 2: The Binary System

Converting Decimal to Binary (Animated)

The Subtraction Method: Let's convert the decimal number 45.

1286432168421
- - - - - - - -
1. Can you take 128 out of 45? No. Put a 0.
2. Can you take 64 out of 45? No. Put a 0.
3. Can you take 32 out of 45? Yes. Put a 1. (45 - 32 = 13 remaining).
4. Can you take 16 out of 13? No. Put a 0.
5. Can you take 8 out of 13? Yes. Put a 1. (13 - 8 = 5 remaining).
6. Can you take 4 out of 5? Yes. Put a 1. (5 - 4 = 1 remaining).
7. Can you take 2 out of 1? No. Put a 0.
8. Can you take 1 out of 1? Yes. Put a 1. (1 - 1 = 0).
Final Binary Number: 00101101

Section 3: The Octal System

The Octal System (Base-8)

Binary gets very long, very fast. Octal was invented to shorten it.

Because binary strings (like 110101110) are hard for humans to read and prone to transcription errors, early computer scientists created the Octal system. It is a Base-8 system, meaning it only uses the digits 0, 1, 2, 3, 4, 5, 6, and 7.

Why Base-8? Because exactly three binary bits (the 4, 2, and 1 slots) can perfectly represent any number from 0 to 7.

Binary (4-2-1)000001010011100101110111
Octal Value01234567
Section 3: The Octal System

Converting Binary to Octal

Break the long binary string into manageable groups of three.

To convert binary to octal, you simply group the binary bits into sets of three, starting from the right side, and translate each group independently using the (4, 2, 1) method.

Let's convert binary 101110 into Octal:

  1. Split it: 101 | 110
  2. Read the first group (4+0+1): 5
  3. Read the second group (4+2+0): 6

The Octal equivalent is 56.

Section 3: The Octal System

Converting Octal to Binary

Just expand each digit back out into three bits.

Going backward is just as easy. Expand each octal digit into its 3-bit binary equivalent.

Let's convert the Octal number 34 into Binary:

  1. Look at the first digit (3). How do you make 3 using (4, 2, 1)? You need the 2 and the 1. So, 011.
  2. Look at the second digit (4). How do you make 4? Just the 4. So, 100.

Push them together. The Binary equivalent is 011100.

Section 4: The Hexadecimal System

Hexadecimal (Base-16)

The modern standard for shortening binary code.

Modern computers group data into 8-bit chunks called "Bytes". Octal (which groups in 3s) doesn't divide evenly into an 8-bit byte. But groups of 4 do perfectly.

A group of 4 binary bits (8, 4, 2, 1) can hold any value from 0 up to 15. Because we don't have single numbers for 10 through 15, Hexadecimal uses letters to represent them.

Decimal0-9101112131415
Hex0-9ABCDEF
Section 4: The Hexadecimal System

Converting Binary to Hex

Break the binary into groups of four (called Nibbles).

Let's convert the 8-bit byte 10101111 into Hexadecimal:

  1. Split it into groups of four: 1010 | 1111
  2. Read the first group (8+0+2+0): 10 (Which is A in Hex)
  3. Read the second group (8+4+2+1): 15 (Which is F in Hex)

The Hexadecimal equivalent is AF.

Whenever you see a MAC address (e.g., 00:1A:2B:3C) or an IPv6 address, you are looking at Hexadecimal.
Section 4: The Hexadecimal System

Converting Hex to Binary

Expand each letter or number back into 4 bits.

Let's convert the Hex code C4 back into Binary.

  1. Look at the first character (C). We know C is 12. How do we make 12 using (8, 4, 2, 1)? We need the 8 and the 4. So, 1100.
  2. Look at the second character (4). How do we make 4? Just the 4. So, 0100.

Push them together. The Binary equivalent is 11000100.

Section 4: The Hexadecimal System

Converting Hex to Decimal

This is slightly harder, but uses the same positional logic.

Because Hex is Base-16, the positional values are powers of 16 (1, 16, 256).

Let's convert Hex 2A to Decimal:

  • The 'A' is in the 1s column. A is worth 10. (10 x 1 = 10).
  • The '2' is in the 16s column. (2 x 16 = 32).

Add them up: 32 + 10 = 42.

Module 7 Review

Summary of Key Concepts

  • Decimal (Base-10): The human standard. Positional values are powers of 10.
  • Binary (Base-2): The machine standard (ON/OFF). Positional values are powers of 2.
  • Octal (Base-8): Groups binary into 3-bit chunks (4, 2, 1). Largely obsolete but still tested.
  • Hexadecimal (Base-16): Groups binary into 4-bit chunks (8, 4, 2, 1). Uses letters A-F to represent 10-15. The modern standard for MAC addresses and memory addressing.
  • Zero: In all of these systems, 0 acts as the critical placeholder.
