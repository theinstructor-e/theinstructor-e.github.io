Interactive Training Tools

A suite of self-contained, browser-based interactive references and trainers supporting the U.S. Army 17E (Electromagnetic Warfare Specialist) program of instruction. Each tool is a single HTML file with no installation, no dependencies beyond a web font, and no internet requirement once loaded — suitable for classroom display, USB distribution, LMS upload, or air-gapped environments.

Classification: UNCLASSIFIED


⚠️ Quality Control / Quality Assurance Notice

These materials are training aids and are still being read through for quality control (QC) and quality assurance (QA). Content is under active review and may contain errors, omissions, or items that do not yet reflect the most current doctrine or the approved program of instruction.

The official lesson slides and the platform instructor in class remain the authoritative source. Where anything in these tools disagrees with the current lesson materials, doctrine publications, or your instructor, the classroom materials take precedence. Use these tools to reinforce and practice — not as a primary or authoritative reference — until QC/QA is complete.

If you identify an error, please route corrections through the course cadre so they can be verified and incorporated.


Using the tools


Open index.html to launch the tool catalog, or open any individual tool file directly in a modern web browser (Chrome, Edge, Firefox, Safari).
Every tool includes a light/dark mode toggle and works fully offline.
Tools are organized by program module (Math, Physics, Basic Electronics, Networking, EW Theory, Systems, Planning).

Technical notes


Single-file design: all HTML, CSS, and JavaScript are embedded; the only external request is to Google Fonts (for typography), which degrades gracefully offline.
No data collection: the tools run entirely client-side and store nothing outside the current browser session.
Interactive calculations (circuit solving, subnet math, RF/antenna formulas) are provided for instructional purposes and validated against standard references, but — per the QC/QA notice above — should be confirmed against approved course materials.
