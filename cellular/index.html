PLMN = MCC + MNC (Public Land Mobile Network)
MCC: 3 digits — ITU country code. US=310-316, UK=234-235.
MNC: 2-3 digits — operator within country.
LAC/TAC: area code within PLMN. CGI = PLMN + LAC + CI.
Identifier Breakdown Diagram
17E: The CGI/ECGI/NCI is broadcast unencrypted in SIBs. Passive collection of these identifiers reveals operator, country, location area, and exact cell identity — all without transmitting.
