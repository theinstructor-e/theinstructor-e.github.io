Mnemonic 7→1: All People Seem To Need Data Processing
◆ Lesson Alignment — E02 Open Systems Interconnection
The OSI model is a conceptual framework standardizing how network nodes communicate across 7 layers. Encapsulation adds headers as data moves down the stack; decapsulation removes them moving up. Each layer's Protocol Data Unit (PDU) has a specific name — knowing where data lives in the stack is the foundation for understanding where EW effects can be applied.
OSI vs TCP/IP Model — how the two map together
OSI vs TCP/IP: The OSI model (7 layers) is the teaching/troubleshooting reference. The TCP/IP model (4 layers) is what the internet actually runs on. TCP/IP collapses OSI's top three layers (Application, Presentation, Session) into one Application layer, and merges Physical + Data Link into one Network Access layer. The middle two — Transport and Network/Internet — map one-to-one.

◆ Lesson Alignment — E03 Media Access Control
MAC addresses operate at Layer 2 (Data Link). They are burned into the NIC and used for communication on the same local network — unlike IP (Layer 3) which routes between networks. MACs are transmitted unencrypted in Ethernet frames, making them visible to anyone sniffing traffic (Wireshark/Kismet) — a key collection and device-tracking consideration for 17E.

ARP — IP to MAC Resolution
17E — ARP SPOOFING: ARP maps a known IP (L3) to a MAC (L2) via broadcast. An attacker can send forged ARP replies associating their MAC with the gateway's IP — intercepting all traffic in a Man-in-the-Middle attack. MAC spoofing also bypasses MAC filtering and hides attacker identity.

◆ Lesson Alignment — E06 IP Addressing & Routing
Layer 3 moves packets between networks using hierarchical IP addresses. Routing: the host compares its IP+mask to the destination to decide local vs remote. If remote, it sends to the default gateway (found via ARP), which consults its routing table and forwards to the next hop. TTL decrements each hop to prevent loops. IPv6 (128-bit) solves IPv4 exhaustion.

◆ Lesson Alignment — E08 Wi-Fi Standards
Wi-Fi is radio transmission tech governed by IEEE 802.11 standards, ensuring interoperability between products. Standards evolved from 2 Mbps (1997) to 23 Gbps (Wi-Fi 7). Key milestones: 1985 FCC released the ISM band for unlicensed use; 1999 Wi-Fi Alliance formed. A 2.4 GHz AP reaches ~100m open-air (10-35m practical indoors).
Frequency Band Occupancy — where it operates
PURPLE band(s) = where the selected standard transmits across the RF spectrum
17E: Each standard's frequency band and modulation (DSSS→OFDM→OFDMA) determines its RF signature and jamming/collection profile. 2.4 GHz penetrates better but is congested; 5/6 GHz offer speed but shorter range. 60 GHz (WiGig) is very high speed, very short range.

◆ Lesson Alignment — E09 Wi-Fi Topology & Channels
The FCC divides spectrum into licensed (auction, high power) and unlicensed (public, low power — Wi-Fi/Bluetooth) bands. 2.4 GHz channels overlap (only 1, 6, 11, and 14 are non-overlapping; the US authorizes only 1-11, and channel 14 is Japan-only) causing adjacent-channel interference. 5 GHz channels don't overlap. 6 GHz (Wi-Fi 6E) adds 1200 MHz of new spectrum with 320 MHz channels for high-capacity networks. Collision management: wired uses CSMA/CD (detection), wireless uses CSMA/CA (avoidance) with optional RTS/CTS.
