◆ How a diode works
A diode is a one-way valve for current. Forward biased (anode positive) it conducts once the voltage exceeds its forward drop Vf \u2014 above that, current rises very steeply (the "knee"). Reverse biased it blocks, passing only a tiny leakage current until reverse breakdown. That one-way behavior is what makes rectification possible.

◆ Rectification
Half-wave uses one diode and passes only the positive halves \u2014 simple but wastes half the cycle (avg \u2248 0.318 × Vpeak). Full-wave bridge uses four diodes to flip the negative halves up too (avg \u2248 0.637 × Vpeak). A smoothing capacitor charges on the peaks and discharges between them, filling the gaps to produce steadier DC with some ripple.

◆ Cutoff \u2192 Active \u2192 Saturation
With no base current the transistor is in cutoff \u2014 off, no collector current. Add base current and it enters the active region where IC = \u03b2\u00d7IB (amplifier behavior). Push enough base current and it saturates \u2014 fully on, like a closed switch, with VCE near zero. Switch and amplifier are the same device in different regions.
