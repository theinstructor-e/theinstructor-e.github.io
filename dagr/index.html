THE SEQUENCE
  1. Insert four AA batteries and close the cover.
  2. PWR/QUIT to turn on. Wait for the satellites. The DAGR shows Present Position when it has a fix.
  3. Hold POS/PAGE for Present Position, then MENU: Select Datum (WGS 84), Select Coordinate/Grid System (MGRS), and Select Grid Resolution (100 m).
  4. Hold WP/ENTER, Mark a WP, WP/ENTER to store it. Do this before you move.
  5. Hold WP/ENTER, GOTO a WP, choose CP 2, WP/ENTER. Walk the way the NAV Pointer arrow points.
  6. Read the grid on Present Position. In a 6-digit grid, take the first three digits of the easting and northing. Do not round.
