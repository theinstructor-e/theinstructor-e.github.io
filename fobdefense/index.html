FOB RF-CUAS LAYERED DEFENSE

Build a notional forward operating base defense using passive radio-frequency awareness, directional RF cueing, fusion and coordination, authorized active effects, and FOB resilience. Randomized simulated aircraft will fly over or approach the FOB when you press RUN RANDOM INCIDENT.

⚠ Training abstraction only. This simulator does not model real device performance, effective range, RF waveforms, satellite-navigation characteristics, equipment settings, response procedures, airspace controls, rules of engagement, or legal authority.

HOW TO USE ▣
1. Select a system from the palette. 2. Click or tap terrain to place it. 3. Select the conceptual active-effect profile. 4. Run a random incident.

Random incidents vary the approach route, aircraft behavior, emitting condition, weather or terrain complication, and simulated control/navigation dependency. The selected effect profile is evaluated only as a high-level training abstraction.
