◆ Lesson Alignment — E02 Open Systems Interconnection
The OSI model is a conceptual framework standardizing how network nodes communicate across 7 layers. Encapsulation adds headers as data moves down the stack; decapsulation removes them moving up. Each layer's Protocol Data Unit (PDU) has a specific name — knowing where data lives in the stack is the foundation for understanding where EW effects can be applied.
OSI vs TCP/IP Model — how the two map together
OSI vs TCP/IP: The OSI model (7 layers) is the teaching/troubleshooting reference. The TCP/IP model (4 layers) is what the internet actually runs on. TCP/IP collapses OSI's top three layers (Application, Presentation, Session) into one Application layer, and merges Physical + Data Link into one Network Access layer. The middle two — Transport and Network/Internet — map one-to-one.
