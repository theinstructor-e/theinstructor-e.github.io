▶ HOW TO USE
This is a pre-captured snapshot of traffic on a small LAN — click any device in the topology to filter the frame list to just that device's traffic, or leave it on All Devices.

Click any row in the frame list to expand its full layer detail below — Ethernet, then IP, then TCP/UDP/ICMP/ARP and the application layer, just like a real capture tool.

Watch for internet-bound traffic: the Ethernet destination is the router (the next hop on this LAN), while the IP destination is the actual remote server far beyond it — MAC addresses are local-link only, IP addresses are end-to-end.
